# Local theme pack for pi

A local pi package containing four dark themes and a command for switching between them.

## Themes

- `oxocarbon` — matched to the Oxocarbon palette used by Ghostty and Neovim
- `cyberdream` — matched to the Cyberdream dark palette
- `aura` — matched to Aura Dark
- `tokyo-night` — matched to the classic Tokyo Night palette

## Usage

After installation or changes, run `/reload` in pi. Then use:

```text
/theme-pack
/theme-pack oxocarbon
/theme-pack cyberdream
/theme-pack aura
/theme-pack tokyo-night
```

The themes are also available in `/settings`.
